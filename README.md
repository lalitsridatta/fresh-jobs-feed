# Fresh Jobs Feed

React + Vite app to browse, filter and save fresh job postings.

## Run
    npm install
    npm run dev

## Features
- Component-based UI (JobCard, FilterBar)
- Loading, error and retry states
- Search and filters with derived state (useMemo)
- Saved jobs persisted with a custom useLocalStorage hook
- Accessible markup (labels, aria-pressed, role="alert", focus styles)
